# IoT-Based Industrial Wastewater Quality Monitoring and Alert System

A web-based IoT monitoring platform designed to monitor industrial wastewater quality using parameters such as **pH, Total Dissolved Solids (TDS), Turbidity, and Temperature**. The project aims to provide real-time monitoring, analytical visualization, alert generation, and reporting to support environmental safety and pollution control.

> **Current Status:** Phase 1 Completed (Frontend Prototype)

---

## 📌 Project Overview

Industrial wastewater contains harmful pollutants that can adversely affect the environment and public health if discharged without proper monitoring. This project proposes an IoT-based solution that enables continuous monitoring of wastewater quality through a modern web dashboard.

The complete system will collect sensor data using an ESP32 microcontroller, transmit it to a cloud platform, and display the information through an interactive dashboard. In the current phase, the frontend has been developed using simulated sensor data.
